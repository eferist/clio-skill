# clio — the DF Labs board, from any Claude Code session

A Claude Code plugin for **Clio**, DF Labs' board. Read and write the board
from any session: orient, check in, report, mint, note. No repo clone, no
token — your board password, cached as a cookie.

```
/plugin marketplace add eferist/clio-skill
/plugin install clio
```

Then say "check in", "report this to clio", "what's on my plate", or type
`/clio:orient`. Full manual below (coming with the first release).
